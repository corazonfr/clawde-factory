CHANGES MADE TO THE BUNDLED PROJECTS
------------------------------------
Each copy is otherwise unmodified upstream source. The edits below exist
only so the games run from a local file with no network:

  hextris    Removed the Google Analytics loader, an AdSense block, and a
             web-font <link>. Also removed a script injection that pulled
             http://hextris.io/a.js at runtime — that domain no longer
             serves the project, so it was loading a stranger's code.
             Nothing in the game depends on any of it.

  dino       Removed a Google Fonts <link>. Deleted the README animation
             GIFs from assets/ (not used by the game).

  racer      Removed the 8 MB soundtrack to keep the download small, and
             guarded playMusic() so it no longer throws without it.

  adarkroom  Repointed jQuery from a CDN to the copy already in the repo
             (lib/jquery.min.js) and removed the analytics tag. Its audio
             engine uses fetch(), which browsers forbid on file:// URLs,
             so under file:// it now resolves to silence instead of
             erroring. Trimmed the translation files to save ~4 MB.

Under GPL-3.0 and MPL-2.0 these modified copies must stay open — the full
source for each is right here in its folder, which satisfies that.

Everything else in the pack — the launcher, the shared styles, the 16
games in games/ — you may use however you like.


==========================================================
  THE GAME SITE IN site/
==========================================================

site/ is a copy of the public "unblocked games" archive published at
ubg98.github.io, plus 15 of the game folders its pages embed, each taken
from the public repository that serves it.

These are commercial games (Slope, Run 3, Vex 3, Cubefield, Idle
Breakout, World's Hardest Game and others) redistributed by that archive
without permission from the studios that made them. That was already the
case upstream; copying it here does not change it. Play it offline;
don't republish or sell it.

Changes made so the copy works with no internet:

  - iframes pointing at https://ubg98.github.io/<Game>/ now point at the
    local folder site/g/<Game>/index.html
  - root-absolute links (href="/page.html") made relative, so the site
    works from any folder rather than only from a domain root
  - pages for the ~166 games not bundled were removed, and the home page
    grid regenerated to list exactly the 15 that are here
  - navigation rebuilt (its category pages no longer exist)
  - unused thumbnails deleted: 203 images down to 15
  - every page gained a notice that appears only when opened as a file,
    explaining why the launcher is needed

The launcher (serve.py) and the START- scripts were written for this
pack and are yours to do anything with.
